# Console artwork

Each console's icon, logo, photo, game stand-in and blurred background, served by the app from this folder.

The art was collected for the original RetroAssembly by arianrhodsandlot in
[retroassembly-assets](https://github.com/arianrhodsandlot/retroassembly-assets) (commit feab5bc), and is copied here
unchanged, except the photos, converted from PNG to WebP to make them smaller. The Nintendo DS and PSP art was added
by this fork from the same sources. The collection itself takes each kind of art from an EmulationStation theme:
